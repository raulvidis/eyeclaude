# Quickstart

1. Clone and install:
   ```bash
   pip install -e .
   ```

2. Start tracking:
   ```bash
   eyeclaude start
   ```

3. Calibrate (first run):
   - Look at top-left corner → SPACE
   - Look at bottom-right corner → SPACE
   - ESC to finish

4. Run:
   - `F8` — pause/resume tracking
   - `F9` — recalibrate
   - `Ctrl+C` — stop
