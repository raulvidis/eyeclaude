# refactor/ — Ephemeral Work Tracking

This directory holds work-in-progress tracking docs. Each doc follows the naming convention:

```
YYYY-MM-DD-topic.md
```

- **Created when starting** a new piece of work
- **Deleted when done** — never leave stale docs

See `superpowers/plans/` for superpowers-driven plan docs (those follow a different lifecycle).
